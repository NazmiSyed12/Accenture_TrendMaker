07 Feedback Loop — detector confidence

An override requires a reason (below), so it can't silently double as an accuracy claim it isn't. The triggering detector's confidence weight decays only on a "not actually risky" reason — a "wrong remedy" override doesn't blame the detector for correctly finding something.

08 Adaptive Risk Memory — behavioral drift

Accumulates against the entity ID (claim/account/vendor), not just the requester — splitting one large action into several small ones against the same entity, even from different sessions, still trips this. Rolling window, matching the brief's own example, so long benign history doesn't eventually trip it by accident.
